Isolert Windows-testpakke for **OsterSea v0.0.3**. Dette er en **prerelease**, ikke en operativ godkjenning.

### Installer
1. Last ned **OsterSea-v0.0.3-ISOLATED.zip** under Assets.
2. Pakk ut lokalt utenfor OneDrive, åpne pakkemappen og kjør `Install-OsterSea.cmd`.
3. Start `%LOCALAPPDATA%\OsterSea-v0.0.3-ISOLATED\Start-OsterSea.cmd` (port **8769**).

Runtime og tidssonedata følger med. Ingen GitHub-innlogging kreves. Egne testdata; ingen gammel data-/Excel-import.

### Automatiske oppdateringssjekker
Appen sjekker denne offentlige, isolerte testkanalen ved oppstart og hver time. Nye versjoner varsles med lenke til offisiell nedlasting. Nettfeil/ratebegrensning rapporteres eksplisitt. Oppdateringer installeres ikke automatisk mens registrering pågår. Den eksisterende signerte `latest.json`-kanalen for den eldre appen er uendret.

### Innhold og avgrensning
Samlet registrering, norsk/engelsk, UTC/tidssone, klokkestilling, typeinnstillinger, lukkede OneDrive-kopier og lokale lesekopier. Åpen SQLite ligger bare lokalt. **Faktisk overtakelse av skriverett er fortsatt sperret**; felles eierkontroll og fysisk to-PC-test gjenstår.

Pakken er usignert. Kontroller `SHA256SUMS.txt`. Ingen prosjektkildefiler, debugfiler, operative databaser, logger, nøkler eller kundeopplysninger publiseres. Python-standardbibliotek og tredjepartsruntime følger sine medfølgende lisenser.
